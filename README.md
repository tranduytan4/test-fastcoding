# Reanty - Modern Real Estate Landing Page

> Front-end Technical Assessment for **FastCoding VN**.  
> Built with **100% Pure HTML5 Semantic & Modern CSS3** (No frameworks, No dependencies).

---

## 🌟 Key Features & Highlights

- **Pure HTML5 & CSS3**: Zero third-party CSS or JS frameworks (no Bootstrap, no TailwindCSS).
- **BEM Methodology**: Strict Block Element Modifier naming convention for maintainable, scalable styles.
- **Pixel-Perfect & Modern Design**: Faithful implementation of typography, harmonious color palette, custom vector SVG icons, and smooth micro-interactions.
- **Full Responsive Design (PC & SP)**: Mobile-first architecture tested seamlessly across:
  - Extra Small Smartphones (< 480px)
  - Small Smartphones (< 640px)
  - Tablets & iPads (768px - 1023px)
  - Desktops (1024px - 1439px)
  - Large Desktop Displays (>= 1440px)
- **Relative Path Architecture**: 100% relative links (`css/style.css`, `images/...`) ensuring smooth deployment on any static server or sub-directory.
- **Clean Assets**: Zero unused files, fully optimized image assets.
